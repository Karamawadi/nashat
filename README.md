# منصة نشاط

منصة أنشطة تعليمية تفاعلية وأوراق عمل بواجهتين:

| | الواجهة الكلاسيكية `/classic/` | الواجهة الذهبية `/golden/` |
|---|---|---|
| القوالب التفاعلية | 22 قالباً | 22 قالباً + نطق صوتي + تلميح ذكي + مؤثرات |
| تبديل القالب والسمة | ✔ | ✔ |
| المكتبة المرجعية (كل المواد) | ✔ | ✔ |
| أوراق العمل | 6 أنماط | 14 نمطاً، أقسام متعددة، مفتاح إجابة، تمايز، حجم خط |
| الذكاء الاصطناعي (Claude) | — | توليد، تحسين، ترجمة، تسهيل/تصعيب، استوديو حزم الدروس، مدرب وشرح للأخطاء |
| التلعيب والتحليلات | لوحة متصدرين | XP ومستويات وأوسمة ولوحة تقدّم ومراجعة ذكية للأخطاء |

## التشغيل

```bash
npm install
npm start            # http://localhost:3000
```

لتفعيل الذكاء الاصطناعي ضع المفتاح على الخادم فقط (لا يصل إلى المتصفح):

```bash
ANTHROPIC_API_KEY=... npm start
```

بدون مفتاح تعمل الواجهة الذهبية بمولّد محلي يعتمد على الكتاب المرجعي.

## الكتاب المرجعي

`library/reference-book.json` هو مصدر كل النماذج الجاهزة. كل مادة تحتوي وحدات، وكل وحدة فيها:

- `items`: أسئلة / أزواج / تصنيف (`prompt`, `answer`, `distractors`, `group`, `hint`)
- `sentences`: جمل لقوالب «ترتيب الجملة» و«الكلمة المفقودة»
- `sequence`: تسلسل مرتّب لقالب «الترتيب الصحيح»
- `words` (اختياري): كلمات مفردة للكلمات المتقاطعة والبحث عن الكلمات

يختار الموقع المجموعة المناسبة لكل لعبة وكل ورقة عمل تلقائياً، فتتولد لكل وحدة 22 لعبة و14 ورقة عمل.
يمكن استيراد كتاب مرجعي آخر من صفحة «المكتبة المرجعية» (JSON بنفس البنية أو CSV بالأعمدة
`subject,unit,grade,set,prompt,answer,distractors,group,hint`).
